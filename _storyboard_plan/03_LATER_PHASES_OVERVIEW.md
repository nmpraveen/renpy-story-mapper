# Later phases overview

Do not give these phases to Codex yet. They exist only to keep the direction clear.

## Phase 02: full-game analysis engine

- Decompose the complete game into manageable evidence scopes.
- Generate a whole-game profile.
- Let AI analyze scopes and cross-scope dependencies.
- Run deterministic coverage audits.
- Send only concrete gaps and conflicts back to AI for repair.
- Preserve hidden, replay, bonus, disconnected, and unresolved content.

## Phase 03: readable storyboard product

- Build the full vertical web storyboard.
- Add search, contents, expandable transcripts, local branch views, rejoins, endings, and route explanations.
- Keep technical evidence available but secondary.

## Phase 04: one command and generalization proof

- Integrate the workflow behind one command.
- Run unchanged code on two known games and one genuinely unseen game.
- Reject any solution requiring game-name patches or manual count assumptions.

## Phase 05: legacy cleanup

Only after the new path works:

- mark stale product paths as legacy;
- remove unused integrations gradually;
- retain only low-level components still used by the storyboard path.
